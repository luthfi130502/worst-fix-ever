Entry for the make.fun bounty [Worst Fix Ever: Funniest Commit Message](https://make.fun/bounty/u-deysumbrella-worst-fix-ever-funniest-commit-message-3f1d9722).

`main.py` (Python 3.13, standard library only) writes a single commit-message
line to `/output/entry.txt`: the subject line for a bug fix that made
everything worse — the slow queries are gone, because so is the table.

Run it with:

```sh
python3 main.py
cat /output/entry.txt
```
